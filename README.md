# JVMAudit

> Find every Java installation on a machine, learn which ones are Oracle-licensed, and export
> audit-ready evidence. Fully offline. Apache-2.0.

**Status: pre-release (v0.1.0 in progress).** The README is written for real at milestone M6.

## Quickstart (placeholder)

```sh
java -jar jvmaudit.jar scan
```

## Trust

- 100% offline: the scanner makes no network calls of any kind.
- No telemetry, ever.
- Apache-2.0 licensed — read the code.

*JVMAudit is an inventory tool, not legal advice. License conclusions depend on your contracts
with Oracle.*
